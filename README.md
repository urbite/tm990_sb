# Scott's tm990 stuff - urbite's fork

https://www.smbaker.com/

This directory contains various projects I worked on for the TM990. In particular, it contains some boards that I designed.
Please find the article(s) on my blog for more information.

- tm990-memory. This is a memory board.

- tm990-multi. This is a multifunction board featuring memory and other features.

Note that tm990-multi-0.7 appears to be the version I fabricated and it must have had some errors
as I ended up making an 0.10 version. It's not clear to me that I ever fabricated the 0.10 version,
so please be aware that version may not have been tested.

## Urbite updates
After discovering this design and Scott's YT video demonstrating it, I contacted Scott and he provided STL files for card guide and backplane hold-down brackets that he design. These have been added in the mechanical directory, with a few photos of the printed brackets in a TM990 system with Stuart Connors backplane.

I had PCBs made using the v0.10 version, but have not finished assembly and initial bringup yet.
